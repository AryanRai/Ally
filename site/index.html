For Claude Code and Codex

Your agents. Your conversations.
Within reach.

Ally keeps your coding agents in a small glass window on top of everything — and on your phone and watch. Ask about anything on screen, get drawn explanations, and let the same chat follow you across devices and accounts.

View on GitHub Get started

Everything around your agents

The agents keep their own tools, sessions, folders and permissions. Ally handles the interface around them.

Pill and notch

A compact glass pill that expands into a full chat. Drag it to the top edge to dock into a notch, where the running reply shows live.

Circle to ask

Select any region of your screen and ask about it. Answers come back with diagrams on a movable drawing board you can sketch on.

Many Codex accounts, one chat

Sign in to several ChatGPT accounts. When one reaches its usage limit, the same chat carries on with your next account — no handoff.

Phone control, anywhere

Let an agent drive your Android phone for a session you approve once, over any network. A Stop button is always one tap away.

Watch, always on

Hold to talk, read replies, review approvals, and keep live agent progress on your Wear OS watch's always-on screen.

Voice that listens back

Local or cloud speech in and out. Speak over a reply to interrupt it; text keeps working when voice is offline.

Visual explanations

See it, not just read it

When words aren't enough, the agent draws. Diagrams, steps and interactive sketches open in a sandboxed board beside the chat — resizable, explorable, and saved with the conversation.

  • Markdown, math, code and tool activity in every reply
  • Drafts per chat, queued follow-ups and Stop
  • Search every Claude Code and Codex chat by keyword

How Ally connects

Your PC stays the hub. Phone and watch reach it through an authenticated bridge; Ally talks to the native agents you already use.

You stay in control

Approvals are real requests from the underlying tools, with explicit answers and expiry.

  • Phone control asks once per session, shows a Stop notification, and uses Android's own unlock prompt
  • Passwords, payments, permission prompts and Send/Delete-style buttons are always left to you
  • Microphone and screen access only on the feature you start
  • Account switching never resends a message that may already have run

Get started

Install a current Node.js LTS and at least one agent — Claude Code or Codex — and sign in to it.

git clone https://github.com/AryanRai/Ally.git
cd Ally/glass-pip-chat
npm ci
npm run dev

Then open Settings → Agents, check the CLI paths, and start a chat. Phone and watch apps are in wear-app.
