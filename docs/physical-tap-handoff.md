## Protocol and Windows helper

`electron/devices/physicalTap.ts` is constructed by the existing authenticated device socket adapter, after its normal bearer authorization and phone hello. Watches cannot arm it. Each socket gets a fresh private32-byte nonce, PC process target ID and short TTL. The WinRT advertiser sends only ALY1 + a rotating random16-byte PUBLIC locator in experimental manufacturer0xffff data. No token, endpoint, pairing secret, device ID or private nonce is broadcast. Advertisement Started is required before target offers. Locators rotate about28 seconds, challenges expire25 seconds after publisher start; all protocol freshness uses local monotonic clocks.

`tap_knock` binds requestId + target + current locator + private nonce to that exact authenticated phone socket. Consume nonce before acknowledging. Reject mismatched/expired/replayed/disconnected/disabled state. Windows powerMonitor lock-screen immediately revokes proofs/advertising; action-time idle-state checks also refuse locked/unknown PC state before the event arrives. `tap_review` returns a fresh one-shot review nonce. The phone accepts only its own outstanding request/target within3 seconds while unlocked/connected. `tap_opened` must echo the review nonce within5 seconds before desktop feedback. Restart/rotation/disconnect revokes outstanding proofs. Public RF evidence never creates a device pairing or authority; this assumes the existing authenticated socket's pairing token is trusted. It does not defend against RF relay/RSSI spoofing, or a compromised already-authenticated phone.

`assets/physical-tap-advertiser.ps1` uses Windows PowerShell5.1 + supported BluetoothLEAdvertisementPublisher. Its tiny C# wrapper keeps WinRT collection operations inside the .NET projection (PowerShell otherwise exposes IVector as __ComObject). The current helper compiles that wrapper in memory using installed Windows SDK UnionMetadata and .NET4.8 reference assemblies, without downloads or settings changes. Missing prerequisites produce an honest unavailable/manual-review message. This dev-PC helper requires those existing SDK/reference assemblies; no portable SDK-free helper binary is claimed. The Electron assets build already copies the script. Only a public locator crosses helper stdin. Stdin closure, explicit stop, process exit and a35-second independent monotonic bound stop advertising. Hidden process windows; no power/radio/security configuration changes.
