# Pill-led selection and drawings

The real Ally pill stays available while selecting and while a drawing is open. Selection tools are an accessory beside it; selecting an area releases directly back to the pill instead of opening a second question form. Selection alone captures/attaches context but sends no agent query. Ask through the existing text or voice input. One exact-chat crop is claimed only with the next real question, while later questions retain the board/sketch context without resending the image. If the selected chat is still answering, the attachment and typed draft remain pending; recognised voice is retained as a draft with a compact explanation rather than stopping that response or silently losing the screenshot.

The drawing chip sits directly below the collapsed composer. It minimises/reopens the canvas, exposes previous/next/latest, freeze, sketch and undo, and keeps the current step's explanation in the pill. Clear explicitly ends/revokes the board. Minimise and Escape preserve the board, turn sketch mode off and suppress auto-reopening from late drawing updates. Changing chat revokes the old capability and discards an unsent selection. The real conversation continues to own voice, drafts, Stop, approvals, history and model routing.

The canvas docks beside the pill, choosing the other side or stacking where space permits. It follows pill move/resize, remains independently draggable, and keeps just its drawing tools/navigation, diagram and minimise control. The duplicate chat-return button and explanation text are removed. Selecting/sketching is the only full-screen pointer capture; otherwise only the canvas controls receive pointer input and other apps remain clickable. Snapshot labels remain explicit and no new capture is performed for follow-ups. Hiding the main window tucks the canvas away too.

Visual parity uses the collapsed pill's translucent black surface, white/10 border, 18px surface radius, 28px controls with 8px corners, muted text, small type and Geist font. The selection accessory no longer has a duplicate Ally brand/input. Existing main-pill styling, layout, behaviour and animations remain, alongside all earlier feature changes.
