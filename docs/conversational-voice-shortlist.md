# Conversational voice shortlist for Ally — 31 Oct 2026

This is a documentation-based engineering shortlist, not a listening benchmark. No provider accounts, paid sessions, model downloads or voice-default changes were made.

Recommended trials: ElevenAgents Expressive Mode as the practical complete-service baseline; Gradium as the speech-layer candidate that preserves Ally's existing Codex/Claude task workers; NVIDIA PersonaPlex as the frontier full-duplex experiment. Compare against current direct Gemini path. Do not nominate a universal winner before testing actual Sydney-network latency and the user's speech/noise conditions.

- ElevenAgents: documented expressive-mode voice, contextual delivery and prosody-aware turn handling. Current docs name Eleven v4 Turbo. Product is an agent stack; do not confuse its speech-model latency with total speech-end-to-audible-reply latency. https://elevenlabs.io/docs/eleven-agents/customization/voice/expressive-mode
- Gradium: developer STT/TTS APIs, streaming, semantic VAD/adaptive turn delays and speech-to-speech documentation. Particularly suitable to testing a speech adapter while retaining existing task reasoning/control brokers. https://docs.gradium.ai/
- NVIDIA PersonaPlex: full-duplex speech-to-speech, listening while speaking, backchannels/interruptions and prompted roles/voices. Public code/weights/self-host path with model-license/Hugging Face access; GPU deployment/bridging tools is additional engineering. Not established as a replacement for Codex/Claude reasoning or permissions. https://research.nvidia.com/labs/adlr/personaplex/ and https://github.com/NVIDIA/personaplex
- Miso Labs: Miso TTS 8B is expressive English speech generation with text/audio context, not an entire conversational task agent. Public repo/local inference path is clear; a self-service hosted developer API was not verified (MisoDocs repository empty). The repo explicitly says advertised110ms is hosted production TTFB on H100-class hardware, not local consumer-GPU end-to-end latency. https://github.com/MisoLabsAI/MisoTTS and https://www.misolabs.ai/
- Sesame: current assistant/app is a useful conversational design reference. Released CSM1B is a base audio generation model, not the full assistant and cannot generate text. Official repo explicitly recommends another LLM for text. No public developer API for the current assistant verified. https://github.com/SesameAILabs/csm and https://www.sesame.com/
- Hume EVI: exclude from a new deployment. Current official docs say EVI/TTS APIs sunset13Nov2026 at12:01amEST. https://dev.hume.ai/voice/docs/speech-to-speech-evi/overview

Evaluate conversation timing as well as pleasant speech: end-of-turn pauses, mid-sentence hesitation, backchannel vs interruption, background music and other speakers, echo, Sydney P50/P95 latency, transcription display, cancellation, tool waits, emotional consistency, API stability and cost. Sesame's TurnBench is a useful methodology reference; a single TTS TTFB ranking cannot decide these outcomes. https://www.sesame.com/journal/turnbench

LiveKit remains a transport/session/orchestration option, not itself a conversational model. Test two providers behind one speech adapter before committing to an infrastructure migration. Preserve push-to-talk/manual Send and existing fallback, chat ownership, request/approval broker and device-control boundaries.
